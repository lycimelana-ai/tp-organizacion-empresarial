# TP Organización Empresarial

## Integrante
Luciana Melana

## Escenario elegido
Análisis de ventas de una pequeña empresa.

## Descripción
Este proyecto analiza un dataset de ventas utilizando Python, Git, GitHub y Jira.

## Estructura del proyecto

- datos/: contiene el dataset CSV
- scripts/: contiene el script de análisis
- resultados/: contiene gráficos y resultados

## Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Git
- GitHub
- Jira

## Instrucciones de ejecución

Ejecutar:

python scripts/analisis_ventas.py

El script genera un gráfico de evolución de ventas dentro de la carpeta resultados.
